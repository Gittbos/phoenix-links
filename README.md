# PHOENIX — сайт-візитка

Адаптивний односторінковий сайт для безкоштовного розміщення на GitHub Pages.

## Перед публікацією
- Instagram: вже додано.
- TikTok: посилання сформовано з ніка `@rodion.x13`.
- Telegram: посилання сформовано з `@VIPU6BOSS`.
- Monobank: не додано, бо посилання ще не надано. Кнопка зараз повідомляє про це, а не веде на вигадану адресу.

## Публікація через iPhone або комп'ютер
1. Увійди або створи акаунт на https://github.com/
2. Створи новий репозиторій із назвою `phoenix-links`.
3. Для найпростішого варіанта зроби його **Public**.
4. У репозиторії натисни **Add file → Upload files**.
5. Завантаж `index.html` з цієї папки та натисни **Commit changes**.
6. Відкрий **Settings → Pages**.
7. У розділі **Build and deployment** обери **Deploy from a branch**.
8. Для Branch обери `main`, папку `/ (root)`, натисни **Save**.
9. Зачекай кілька хвилин. Адреса зазвичай матиме вигляд:
   `https://ТВІЙ-НІК.github.io/phoenix-links/`
   GitHub покаже точну адресу в Settings → Pages.

## Як додати Monobank пізніше
1. Відкрий `index.html` у редакторі.
2. Знайди кнопку з текстом `ПІДТРИМАТИ НА MONOBANK`.
3. Коли матимеш точне посилання на банку, заміни кнопку на посилання `<a class="link support" href="ТВОЄ_ПОСИЛАННЯ" target="_blank" rel="noopener noreferrer"> ... </a>` та прибери повідомлення `supportNote` і скрипт alert наприкінці файлу. Не публікуй адресу, доки не перевіриш, що вона веде саме на твою банку.

GitHub Pages безкоштовний для цього статичного сайту. Власний домен на кшталт `.com` не входить у безкоштовний хостинг.
